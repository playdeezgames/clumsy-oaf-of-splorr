# Clumsy Oaf of SPLORR!!, rebuilt for the browser

(Draft for the itch.io devlog. Type: Major Update. Posted by hand or, if the user asks, through Chrome with the AI-agent line at the end.)

Clumsy Oaf of SPLORR!!, my Soulslike Game Jam #3 entry, has been rebuilt in Odin and WebAssembly, like a lot of my older metaphors this autumn. Same Blue Room, same maze, same slimes telling you what they are about to do, same clumsiness.

What changed:

- It saves as you play, in your browser, and picks up where you left off, even in the middle of a fight. The old version never saved.
- Improve Health at the checkpoint works now. It was on the menu and did nothing.
- If several slimes are lined up and the first one kills you, the others stop. They used to keep going, and every extra "death" swapped your gravestone for an empty one, so yer cruor was gone for good.
- Improve Attack says it improved attack (it used to say defend).
- The stamina messages say what actually changed.
- If you do not type a name, you get the default name the original always meant to give you.
- It has a layout for phones held upright, and you can tap the choices.

Losing is still fun.

The latest version is always at https://playdeezgames.github.io/clumsy-oaf-of-splorr/ too.
